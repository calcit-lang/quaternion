# 2026-09-05 Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

- Upgrade Quaternion and `@calcit/procs` from Calcit 0.13.32 to 0.13.77.
- Keep the package and `deps.cirru` module versions aligned at 0.2.3.
- Replace the archived `calcit-test` dependency with the built-in `calcit.test`
  namespace because Calcit 0.13.77 rejects its legacy macro schema.
- Migrate the old test wrappers to ordinary zero-argument test functions and
  built-in `calcit.test/is`, then commit a per-definition quality baseline so
  CI rejects new debt.
- Mark the README's constructor-shape notation as illustrative `cirru.no-check`
  so documentation validation does not execute placeholder field names.
- Revalidate canonical Snapshot formatting, native and JavaScript compilation,
  baseline-gated static quality, and the quaternion math tests.

- 将 Quaternion 与 `@calcit/procs` 从 Calcit 0.13.32 升级到 0.13.77。
